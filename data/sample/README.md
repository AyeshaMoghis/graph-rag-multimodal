# Sample corpus

Three openly licensed papers so the pipeline runs end to end without the
private lecture corpus. All are distributed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); files are unmodified
copies of the arXiv PDFs, renamed.

| File | Paper | Authors | Source |
|---|---|---|---|
| `vijayaraghavan2021_multimodal_hate_speech.pdf` | Interpretable Multi-Modal Hate Speech Detection | Prashanth Vijayaraghavan, Hugo Larochelle, Deb Roy | [arXiv:2103.01616v1](https://arxiv.org/abs/2103.01616v1) |
| `sharevski2022_folk_models_misinformation.pdf` | Folk Models of Misinformation on Social Media | Filipo Sharevski, Amy Devine, Emma Pieroni, Peter Jachim | [arXiv:2207.12589v1](https://arxiv.org/abs/2207.12589v1) |
| `sharevski2023_older_adults_misinformation.pdf` | Older Adults' Experiences with Misinformation on Social Media | Filipo Sharevski, Jennifer Vander Loop | [arXiv:2312.09354v1](https://arxiv.org/abs/2312.09354v1) |

The results in the main README come from a different, private corpus; these
samples are for trying the pipeline, not for reproducing those numbers.
